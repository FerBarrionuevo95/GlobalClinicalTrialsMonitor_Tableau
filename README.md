# Global Clinical Trials Monitor - Tableau

### Data Analysis & Visualization

**Academic project focused on exploring global clinical trials data through interactive visualization.**

**Project type:** Academic Project — Data Analytics
**Role:** Data Preparation · Data Analysis · Dashboard Design
**Tools:** Tableau · Excel

---

## The Project

This project focused on analyzing a dataset related to clinical trials around the world and transforming the information into interactive visualizations using Tableau.

The project involved preparing and exploring the data to identify relevant patterns, geographical distribution and differences across clinical trials.

---

## The Objective

The main objective was to transform the dataset into an interactive dashboard that could facilitate the exploration of clinical trials from different perspectives.

The analysis focused on:

* Geographical distribution
* Clinical trial volume
* Categories and classifications
* Top-performing or most represented groups
* Detailed information through interactive filters

---

## Data Preparation

The dataset was prepared and explored before creating the visualizations.

The process included:

* Data preparation and normalization
* Applying filters
* Working with aggregated values
* Exploring different dimensions of the dataset
* Preparing the information for visualization in Tableau

---

## Dashboard

The final project uses Tableau to combine different visualizations and interactive elements into a single analytical experience.


---

## Data Visualization

The dashboard includes different visual perspectives, including:

* Geographic visualization
* Comparative analysis
* Top 5 analysis
* Detailed data exploration
* Interactive filters


---

## Key Analysis

The visualizations make it possible to explore differences across countries, categories and other dimensions of the dataset.

The interactive structure allows users to filter the information and examine specific segments in greater detail.

---

## Outcome

The project resulted in an interactive Tableau visualization that transforms a structured clinical trials dataset into an accessible analytical dashboard.

The project strengthened my skills in:

**Data preparation → Data exploration → Visualization → Interactive analysis**
